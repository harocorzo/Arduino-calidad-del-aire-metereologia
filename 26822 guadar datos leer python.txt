Pasos para graficar datos de Arduino en Windows
1.Instalar la librería de comunicación serie en Windows:
    Abre la Terminal de Windows o el Símbolo del sistema (CMD) y ejecuta este comando para instalar la librería que usará el script:
        pip install pyserial
2.Identificar el puerto COM asignado:
    Conecta la placa Arduino por USB a la PC con Windows.
    Presiona las teclas Win + X y selecciona Administrador de dispositivos.
    Despliega la sección Puertos (COM y LPT) y fíjate qué número de puerto 
    le asignó Windows (por ejemplo: COM3, COM4 o COM5).
3.Adaptar y guardar el script de Python:
    Crea un archivo llamado capturar_mq135.py en Windows (usando el Bloc de notas o VS Code) con el código:

import serial
import csv
import time

# Cambia 'COM3' por el puerto exacto que viste en el Administrador de dispositivos
puerto = 'COM4' 
baudios = 9600

try:
    ser = serial.Serial(puerto, baudios, timeout=1)
    time.sleep(2)

    with open('datos_mq135.csv', mode='a', newline='') as archivo:
        escritor = csv.writer(archivo)
        if archivo.tell() == 0:
            escritor.writerow(['Tiempo', 'Valor_Analogico'])

        print("Capturando datos en 'datos_mq135.csv'... Presiona Ctrl+C para detener.")

        while True:
            linea = ser.readline().decode('utf-8').strip()
            if linea.isdigit():
                tiempo_actual = time.strftime('%Y-%m-%d %H:%M:%S')
                escritor.writerow([tiempo_actual, linea])
                archivo.flush()
                print(f"[{tiempo_actual}] Guardado: {linea}")

except KeyboardInterrupt:
    print("\nLectura finalizada por el usuario.")
except Exception as e:
    print(f"Error: {e}")

4.Ejecutar la captura en Windows:
Abre CMD o PowerShell en la carpeta donde guardaste tu script y ejecuta:
    python capturar_mq135.py
El proceso en Windows comenzará a guardar exactamente el mismo archivo datos_mq135.csv con la fecha, hora y lecturas analógicas en el disco duro de esa computadora.
